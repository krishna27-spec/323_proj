      About

      Chatter Monitor shows what one or more accelerometers on a micromilling spindle measure while the machine cuts. You see the time signals, their spectrum, a waterfall of recent spectra, the strongest frequencies and the process state: 0 air cutting, 1 stable, 2 transition, 3 chatter.

      The state comes from a CNN + GRU network trained on the raw signal, checked against an entropy rule on the spectrum. When the two disagree while the tool is cutting, the state is transition.

      Demo plays three test recordings (20 kHz, never used for training). Live reads the DAQ through scope.py running on the measuring PC; open http://localhost:8050/app/ there, or choose Live on this page and allow access to the local network when the browser asks.
